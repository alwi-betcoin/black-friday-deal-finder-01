DealHunt Friday is a static deal finder with 34 real Black Friday deals checked on Fri 27 Nov 2026 across 6 stores and 10 categories, each with sale price, usual price, discount, an honest verdict (true low / strong / routine / inflated anchor), its source and check time, plus working search, category/store/discount filters, sorting, deal scores and same-product cross-store comparisons.

## Run it

```sh
node serve.ts   # serves app/ at http://localhost:8080
```
